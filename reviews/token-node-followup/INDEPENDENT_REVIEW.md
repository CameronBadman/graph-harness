# Independent review: repaired node editing development rerun

The eligibility repair worked on the three tested targets, and every enabled scored run used the node editor successfully. It did **not** establish whole-task token savings. All four graph configurations increased aggregate input and output relative to the contemporaneous native control; none passed the registered continuation gate.

I did not author the product changes, task fixtures, runner or collector. I reviewed them, raised issues before freeze, audited the retained observations and independently recomputed outcomes. The integrating agent owns commits. This review covers the frozen development rerun; it does not replace or amend the earlier negative study.

All 24 graph runs used bundles; all 12 format-enabled runs received source-v1. Shell validation and inspection remained: node and combined issued 19 and 18 shell calls respectively after their first commits. Their receipts correctly said syntax checked and project tests not run.

Every graph overload run first received an ambiguous bundle without source. Seven then selected the proper `node_id`; slim repetition 2 continued with native reads. Both node overload runs later retrieved another bundle for a second commit. Long-method bundles reported truncation, and native helper/constructor reads continued. Some raw responses repeated target source already returned by the graph. I verified 47 returned source slices against their hash-bound byte spans and reconstructed all 14 node commit byte results without a mismatch. Raw tool results do not prove how much code-mode wrappers ultimately exposed to the model.

The node interface requires a full replacement body. Long-method node payloads were 1,894 UTF-8 bytes, except one indented payload of 2,270 bytes, for a repair whose essential source difference is one line. Native control diffs changed that line locally. Native patch payloads are absent from file-change JSONL records, so this is not an equal-basis generated-byte comparison. Bytes are not tokens, and exact token costs of payloads, discovery, instructions, reasoning and rereads are not separately measured.

Formatting caused material extra work. In both `java_overload-1-node` and `java_overload-2-node`, the first replacement's mixed indentation produced doubled indentation after its first line. Both first commits already passed their focused probes. Each then read source, refreshed the bundle and made a whitespace-only second commit. The same pattern in `java_long-1-node` added eight spaces to 47 subsequent body lines and remained in the final file. Passing behavior/scope does not establish formatting quality. These artifacts were not normalized after scoring. Refreshed overload graphs included the agents' own scratch probes as callers; those were self-authored workspace sources, not hidden evaluator leakage.

There were 47 nonzero shell events: 28 Git nonrepository errors, three probe compilation failures, five probe assertion failures, two JShell socket failures, three searches naming missing paths, five build/test-file searches with no matches, and one expected absence check for the old buggy line. Three additional zero-exit compound commands printed an inner Git/search error. Probe failures concerned constructor arguments or expected behavior; agents fixed their own probes while the production repair was already correct. Several commands passed tests and then failed on Git or a no-match search. All costs remain included; these outcomes must not be relabeled as node-editor failures or access violations.

## Limits and decision

This is an explicitly guided development rerun of three already-known tasks, two repetitions and one shared 24-file corpus. The answers and earlier trajectories informed authorized diagnosis and repair. A common compilation/behavior requirement was added equally to all arms before freeze, and graph guidance changed. Therefore old/new results cannot isolate the matcher fix causally, and this is not an untouched holdout or a representative production estimate. Current controls were rerun, and the registered schedule, fixtures, evaluator and product stayed frozen during scoring.

The external evaluator is not an OS sandbox; inspected commands and probe code support the access judgment but cannot prove absence of every unobserved action. JSONL omits private reasoning and code-mode wrappers. Cache is uncontrolled, system runtimes are not fully pinned, and the small number of related cells cannot support broad statistical claims.

The evidence supports repaired eligibility and full guided node-editor use on the tested cases. It rejects the claimed token-efficiency win for this measured workflow. Any further interface or formatting change needs a separate experiment, preserving these negative results and using fresh tasks before making generalization claims.
