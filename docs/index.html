RUN IT LOCALLY

Start with the public fixture.

GraphHarness is a local developer tool. The daemon is explicit, browser pairing is local, and the browser does not receive a bootstrap credential.

git clone https://github.com/CameronBadman/graph-harness.git
cd graph-harness
./scripts/build_live.sh
build/install/graphharness/bin/graphharness daemon examples/ticket-office

Current capability boundary

Java, TypeScript, JavaScript and Python structural navigation; opt-in coordinated Java method-body edits. The daemon identifies its parser and backend. New-language adapters provide definitions, source spans and containment; semantic calls and edits remain unavailable for them. Graph relationships may be incomplete, and a reservation coordinates cooperating daemon clients rather than arbitrary editor writes.
